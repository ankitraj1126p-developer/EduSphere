# EduSphere – Student Management System

## 📌 Project Overview

EduSphere is a responsive Student Management System developed to simplify student record management and academic activities.

The website provides an easy-to-use dashboard where an administrator can manage student information, attendance, marks, fees, assignments, and academic events.

This project was developed as part of the **InternNova Week 6 Web Development Internship**.

## ✨ Features

- **Dashboard:** Displays total students, present students, courses, and pending fees.
- **Student Management:** Add, edit, delete, search, filter, and sort student records.
- **Attendance Management:** Mark students as present, absent, or on leave.
- **Marks & Grades:** Manage student marks and academic performance.
- **Fee Management:** Track fee records and pending payments.
- **Assignments:** Manage assignments and submission statuses.
- **Calendar:** Manage academic events.
- **Activity Log:** View recent activities.
- **Dark and Light Mode:** Switch between themes.
- **Data Storage:** Save application data using browser Local Storage.
- **Import and Export:** Import/export student data and create backups.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.
